# External references

This page lists the Microsoft Learn pages for each feature of Update Planner. Each link was opened and checked on 2026-11-06. The same links are in the Links section at the end of each page.

- [Introduction to software updates in Configuration Manager](https://learn.microsoft.com/intune/configmgr/sum/understand/software-updates-introduction): Explains how the site manages software updates.
- [Fundamentals of role-based administration](https://learn.microsoft.com/intune/configmgr/core/understand/fundamentals-of-role-based-administration): Describes the security roles, including Read-only Analyst.

### [Plan page](core/plan.md) and [Plan grids](core/plan-grids.md)

- [Introduction to software updates in Configuration Manager](https://learn.microsoft.com/intune/configmgr/sum/understand/software-updates-introduction): Explains the software update workflow.
- [Manually deploy software updates](https://learn.microsoft.com/intune/configmgr/sum/deploy-use/manually-deploy-software-updates): Describes how to create a software update deployment.

### [Report and export](core/report-and-export.md)

- [Use maintenance windows](https://learn.microsoft.com/intune/configmgr/core/clients/manage/collections/use-maintenance-windows): Explains how maintenance windows limit when updates install.

### [Deploy page](core/deploy.md)

- [Manually deploy software updates](https://learn.microsoft.com/intune/configmgr/sum/deploy-use/manually-deploy-software-updates): Describes how to deploy software updates.
- [Monitor software updates](https://learn.microsoft.com/intune/configmgr/sum/deploy-use/monitor-software-updates): Describes how to check the state of a deployment.

### [Options dialog](core/options.md) and [Getting started](getting-started.md)

- [Install the Configuration Manager console](https://learn.microsoft.com/intune/configmgr/core/servers/deploy/install/install-consoles): Describes how to install the console.

### [Command line](core/command-line.md)

- [about_CommonParameters](https://learn.microsoft.com/powershell/module/microsoft.powershell.core/about/about_commonparameters): Describes `-WhatIf` and `-Confirm`.
